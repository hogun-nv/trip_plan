# The City Index — New York

2026년 9월 기준으로 조사한 뉴욕 취향 가이드입니다. 맛집, 볼거리, 문화, 쇼핑, 근교 여행지를 사진·핵심 정보·지도와 함께 탐색할 수 있습니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

## GitHub Pages 빌드

```bash
npm run build:github
```

정적 결과물은 `dist-github/`에 생성되며, 이 저장소의 Pages 배포에서는 `/guide/` 경로에 게시합니다.

- 운영 페이지: <https://hogun-nv.github.io/trip_plan/guide/>
- 소스 브랜치: `guide`

장소 운영시간·가격·예약 방식은 바뀔 수 있으므로 방문 직전 각 항목의 공식 페이지에서 다시 확인하세요. 이미지 출처와 라이선스는 화면의 사진 캡션에 표기합니다.
